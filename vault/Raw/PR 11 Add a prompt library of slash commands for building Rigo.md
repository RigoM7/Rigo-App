# PR #11: Add a prompt library of slash commands for building Rigo

https://github.com/RigoM7/Rigo-App/pull/11 · state: closed · merged: 2026-10-06T11:59:59Z

## What
A home for the owner's reusable prompts for building Rigo: `.claude/commands/`, where each file runs as `/<name>` in a Claude session.

- `/new-prompt <idea>` — turns an idea into a new prompt in the library and lists it in `CLAUDE.md`
- `/feature <feature>` — builds a feature end to end (server, client, tests, docs)
- `/screen <screen and change>` — designs, builds or redesigns a screen following `docs/DESIGN-SYSTEM.md` and `docs/UI-GUI-PROMPT.md`
- `/fix <bug>` — reproduces the bug with a failing test, then fixes the root cause
- `/review [PR or branch]` — checks changes against Rigo's rules (isolation, permissions, money, honest states, demo safety, migrations, UI, tests, docs)
- `/ship [summary]` — runs the checks, updates `docs/IMPLEMENTATION-STATUS.md`, pushes once and opens a draft PR; never merges without the owner

The prompts link to the docs instead of copying them, so they stay correct when the docs change. `CLAUDE.md` gets a "Prompts" section that lists them.
